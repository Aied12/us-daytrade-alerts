# دومين + HTTPS + إشعارات الجوال

## الآن (بدون شراء دومين)

بعد التحديث على الـ VPS افتح الرابط الآمن:

**https://daytrade.2.28.129.241.sslip.io/**

هذا دومين مجاني مؤقت يشير لسيرفرك ويعمل مع شهادة HTTPS تلقائياً.

### تفعيل الإشعارات على الآيفون

1. افتح الرابط **HTTPS** أعلاه في **Safari**
2. مشاركة → **إضافة إلى الشاشة الرئيسية**
3. افتح التطبيق من الأيقونة (مو من تبويب Safari)
4. ⋯ → **🔔 إشعار** → اسمح

تصلك إشعارات الفرص العاجلة حتى لو التطبيق بالخلفية.

---

## لاحقاً: دومين خاص باسمك

1. اشترِ دومين (Namecheap / Cloudflare / GoDaddy…)
2. أضف سجل DNS من نوع **A**:
   - Host: `@` أو `daytrade`
   - Value: `2.28.129.241`
3. على السيرفر في ملف `.env`:
   ```bash
   DOMAIN=daytrade.yourdomain.com
   ```
4. أعد التشغيل:
   ```bash
   cd /opt/us-daytrade-alerts/deploy/vps
   docker compose up -d
   ```

Caddy يجدّد شهادة HTTPS تلقائياً.
